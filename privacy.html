Privacy Policy

Last updated: 22 November 2026

starGaming Uploader ("the tool") is a private upload script used only by the owner of the starGaming YouTube channel. This policy explains what data the tool accesses and how it is handled.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the tool accesses

  • Google account authorisation: an OAuth access/refresh token for the owner's own Google account, with the scopes youtube.upload and youtube.readonly.
  • The owner's channel data: the channel name and ID and the titles and IDs of the owner's recent uploads, used only to confirm the right channel is signed in.
  • The owner's own video files and metadata (title, description, tags) that the owner chooses to upload.

The tool does not access, collect or store any data about other YouTube users, viewers or channels.

How data is used, stored and shared

  • Data is used only to upload the owner's videos and keep the owner's own upload log.
  • The OAuth token and the upload log are stored only on the owner's computer. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising.
  • The tool uses no cookies or tracking.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page (Third-party apps & services). Deleting the local token file removes all stored authorisation data. Stored API data is refreshed or deleted within 30 days.
